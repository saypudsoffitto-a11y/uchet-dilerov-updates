# Учёт дилеров 8.9.16

- Голос помощника стал мягче и естественнее: программа в первую очередь выбирает доступный в Windows русский женский голос Natural.
- Темп речи немного снижен, чтобы цены, остатки, долги и подтверждения звучали понятнее.
- Если Natural-голос на компьютере отсутствует, программа автоматически использует лучший доступный русский женский голос.
- Все функции и ограничения версии 8.9.15 сохранены: микрофон запускается только кнопкой, изменения требуют подтверждения, удаление голосом запрещено.

Сборка основана на последней выпущенной Windows-версии 8.9.15.
