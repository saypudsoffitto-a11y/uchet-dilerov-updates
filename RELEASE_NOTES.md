# Учёт дилеров 8.9.59

- Исправлено обновление Windows-версии, установленной внутри Parallels на MacBook.
- Обновлятор теперь пробует несколько адресов GitHub: raw-манифест, latest release asset и GitHub API, поэтому отказ одного маршрута/VPN больше не должен останавливать обновление.
- После скачивания установщик хранится в папке данных программы, а не только во временной папке Windows.
- Для запуска обновления сначала используется системный PowerShell, затем CMD, и только потом Electron/Node fallback — это устойчивее в виртуальной Windows Parallels.
- Сохранены все функции и исправления 8.9.58 для Windows и macOS.
