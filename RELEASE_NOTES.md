Учёт дилеров 8.9.33

Исправление ядра удаления дилеров, синхронизации и голосового помощника.

Дилеры:
- Команда удаления теперь реально удаляет карточку из активного списка и сразу сохраняет это состояние.
- Старые продажи, чеки и оплаты не удаляются: перед удалением в операции сохраняются имя, телефон, город и компания дилера.
- Добавляется отметка удаления (tombstone), которая передаётся через синхронизацию. Старая карточка со второго компьютера или с сервера больше не должна появляться обратно после удаления.
- При конфликте синхронизации побеждает более позднее реальное изменение. Старый снимок карточки не отменяет более новое удаление.
- Исправления применяются финальным слоем после старых runtime-модулей, поэтому прежняя функция удаления больше не должна перезаписывать исправленную.

Голосовой помощник:
- Включена озвучка ответов при переходе на 8.9.33.
- Сохранён естественный облачный голос OpenAI, если облачная речь подключена и есть API-ключ.
- Для обычного Windows-режима добавлен отдельный резервный канал через системный речевой движок Windows. Если Chromium/Electron не запускает speechSynthesis или не видит русский голос, ответ передаётся в Windows TTS вместо тишины.
- В настройках помощника добавлена кнопка «Проверить голос».
- Голосовой ввод по кнопке и запрет фонового прослушивания сохранены.

Обновление:
- Сохраняется исправление 8.9.32: при обновлении через кнопку программы обычное окно «Остаться / Закрыть программу» не вызывается. Приложение закрывается, и установщик запускается только после полного завершения процесса.

Остальные функции:
- Стандартное меню правой кнопки мыши, удаление товаров с защитой истории, кнопка «Назад» и остальные исправления предыдущих версий сохранены.
- NewMatRos не изменялся.

Перед публикацией выполняются функциональные тесты: реальное удаление карточки с сохранением операций, конфликт удаления со старой серверной карточкой, восстановление только более новой правки, голосовой fallback Windows и сохранение облачного OpenAI TTS.
