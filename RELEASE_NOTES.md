# Учёт дилеров 8.9.51

- Интерфейс приведён к утверждённому компактному виду: светлая боковая панель, цветовые акценты разделов и более плотные списки на основных экранах.
- Высота строк в списках дилеров, товаров, групп, оплат, долгов и истории уменьшена без искусственного растягивания интерфейса.
- Экран «Долги» переработан по утверждённому макету: показатели сверху, компактные поиск/сортировка, последняя оплата и кнопка «Внести оплату» прямо в строке дилера.
- Чек/накладная сделан компактнее. Позиции нумеруются 1, 2, 3…; столбец «Артикул» из чека и JPEG-картинки убран.
- WhatsApp по-прежнему получает чек как JPEG. Высота JPEG теперь обрезается по фактическому содержимому, поэтому для 1–2 позиций нет большого пустого белого поля.
- Сохранены действия с чеком: изменение количества/цены, удаление отдельной позиции с пересчётом долга, добавление товара в существующий чек, «Удалить этот чек» с архивом и восстановлением.
- Сохранён компактный текст NewMatRos для полотна: материал, рулон и узкая/широкая плёнка без служебных фраз.
- Сохранены дедупликация дилеров и безопасное объединение данных нескольких ПК, PIN-код, автообновление, архив чеков и все исправления 8.9.50.
