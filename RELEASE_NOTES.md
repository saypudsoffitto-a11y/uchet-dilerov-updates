# Учёт дилеров 8.9.52

- Кнопка обновления больше не требует ручного ввода адреса сервера.
- Адрес `latest.json` встроен в программу и используется автоматически.
- Даже если поле/настройка адреса пустая, updater сам берёт встроенный адрес и проверяет новую версию.
- Перед обновлением по-прежнему автоматически сохраняется резервная копия данных.
- Сохранены все изменения 8.9.51: утверждённый компактный интерфейс, плотные списки, переработанный экран «Долги», компактный чек без артикула, JPEG для WhatsApp, архив/восстановление чеков, NewMatRos, синхронизация и защита от дублей.
