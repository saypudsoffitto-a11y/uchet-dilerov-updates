# Учёт дилеров 8.9.62

- WhatsApp/JPEG: знак ₽ больше не переносится на отдельную строку после суммы; цена и сумма выводятся одной строкой.
- NewMatRos: из описания полотна полностью убраны префиксы «Потолок 1», «Потолок 2», «Потолок 3» и т. д.; старые сохранённые позиции NewMatRos также очищаются.
- Долги: убран лишний дублирующий столбец «Оплата»; остаётся одна кнопка «Внести оплату» в столбце «Действие».
- Добавлен отдельный раздел «Прайс» в левом меню: поиск по товарам, фильтр по группам, розничная и оптовая цена, единица измерения, копирование и печать прайса.
- Сохранены все функции и исправления версии 8.9.61, включая общий сервер и синхронизацию Windows/macOS.
