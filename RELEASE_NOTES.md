# Учёт дилеров 8.9.65

- Перед любым обновлением программа автоматически создаёт резервную копию. Если резерв не создан успешно, установка не запускается.
- Исправлены чёрные служебные окна CMD/findstr после обновления: видимый CMD-helper удалён, оставлены два скрытых независимых механизма запуска установщика.
- Исправлено первое подключение третьего компьютера: общая серверная база, продажи, оплаты и долги загружаются, а уникальные локальные операции сохраняются и не теряются.
- Добавлена защита от повторного добавления одинаковой операции при первом подключении рабочего компьютера.
- При настоящем конфликте одной операции с одинаковым ID и разными данными синхронизация останавливается без перезаписи.
- Добавлен гарантированный запрос общей базы после инициализации защищённой синхронизации, чтобы рабочий компьютер не оставался со старым локальным долгом.
- Если сервер синхронизации не отвечает, через 12 секунд программа показывает понятное сообщение вместо бесконечного «Подключение к серверу…».
- Сохранены исправления 8.9.64: компактный список накладных/оплат в карточке дилера, открытие выбранного чека двойным щелчком, JPEG WhatsApp и защита локальных оплат.
