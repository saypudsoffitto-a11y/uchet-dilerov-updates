# Учёт дилеров 8.9.16 — черновик, не выпуск

Основано на выпущенной Windows-версии 8.9.15. Не готово для автообновления.

- Черновик чека по команде «Создай чек Ахмеду Карчеги» после подтверждения.
- Диктовка товара и количества; если количество не названо, помощник переспрашивает. Неоднозначный товар не выбирается автоматически.
- Локальные подтверждённые синонимы: «Запомни: парящий профиль = профиль Fly 01».
- Отдельное окно цены с названием, типом цены, крестиком и кнопкой «Закрыть», без перехода в другой раздел.
- Добавленные строки доступны для обычного ручного исправления количества, цены и суммы; ошибочную позицию можно убрать вручную.
- Отдельная кнопка настроек, управление микрофоном и озвучиванием, просмотр/удаление соответствий и очистка только памяти помощника после подтверждения.
- Финансовые ответы отображаются локально. Синтез получает только фиксированную нейтральную фразу.
- Русские команды, порядок слов, количество и десятичные размеры обработаны в локальной логике.

Ограничения: онлайн-провайдер с подходящим бесплатным лимитом ещё не выбран. Существующие SpeechRecognition и speechSynthesis не заменены полноценным ИИ. Естественный онлайн-голос не готов. Произнесённые суммы могут попасть сервису распознавания, поэтому суммы вводятся вручную. Память синонимов пока только на этом компьютере. Windows, реальная речь и сетевой трафик не проверены.
