# Учёт дилеров 8.9.57

- Исправлена публикация версии 8.9.57: релиз теперь собирается отдельно для Windows и macOS Apple Silicon (M1/M2/M3).
- Исправлено обновление на MacBook: старый Windows-ориентированный модуль больше не перехватывает обновление macOS.
- На macOS используется основной ZIP-механизм обновления: новая версия скачивается, приложение заменяется и запускается снова; при отсутствии прав на системную Applications используется пользовательская папка Applications.
- Файл latest-macos.json переключается на 8.9.57 только после успешной сборки и проверки ARM64-приложения.
- Сохранены исправления 8.9.55: удалённые товары и пустые карточки больше не должны возвращаться после синхронизации, обновлятор имеет запасные адреса GitHub.
- Сохранены изменения интерфейса: компактный чек, JPEG по размеру накладной, плотные таблицы, «Назад» и Escape.
