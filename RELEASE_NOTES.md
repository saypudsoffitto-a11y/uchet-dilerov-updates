# Учёт дилеров 8.9.58

- Финализирована нативная сборка для macOS Apple Silicon (arm64), включая MacBook M1.
- macOS-приложение теперь собирается с ad-hoc подписью; перед публикацией CI проверяет подпись, архитектуру arm64 и номер версии внутри .app.
- Для первой установки публикуются готовые DMG и ZIP. После установки обновление на macOS остаётся автоматическим через ZIP с заменой и перезапуском приложения.
- Исправлен выбор файла NewMatRos на Mac: диалог открывается из «Документов», а не из Windows-пути C:\\NewMatRos Standart.
- Убраны Windows-only подсказки из WhatsApp/JPEG на macOS.
- Сохранены все исправления 8.9.57 и 8.9.55: компактный чек, JPEG в WhatsApp, плотный интерфейс, «Назад»/Escape, синхронизация удаления товаров и очистка пустых карточек.
