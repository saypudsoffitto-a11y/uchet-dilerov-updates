# Учёт дилеров 8.9.17

- Исправлена автоматическая связь с NewMatRos: наблюдение за папкой NewMatRos теперь включается само при каждом запуске программы.
- При получении новой выгрузки NewMatRos появляется заметное уведомление поверх рабочего экрана с кнопкой «Открыть».
- Сохранён автоматический расчёт плёнки по материалу, цвету и ширине, включая отдельную категорию MAT-303 5,80 м.
- Голосовой помощник теперь выбирает наиболее естественный русский голос из доступных в Windows. При наличии Natural/Neural-голоса он получает приоритет.
- В настройках помощника добавлен выбор русского голоса вручную.
- В разделе «Долги» у каждого дилера появилась кнопка «Внести оплату», которая сразу открывает форму оплаты нужного дилера.
- В разделе «Товары» добавлен отдельный фильтр «Группа товаров»: можно выбрать группу и сразу видеть только товары этой группы; обычный поиск продолжает работать внутри выбранной группы.
- Все функции и исправления версии 8.9.16 сохранены.

Готово для автоматического обновления с версии 8.9.16.
