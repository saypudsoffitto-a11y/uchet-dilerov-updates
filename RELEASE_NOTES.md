# Учёт дилеров 8.9.68

- Все рабочие списки и таблицы сделаны одинаково компактными: уменьшены шрифт, высота строк и вертикальные отступы, чтобы на экране помещалось заметно больше дилеров, товаров, чеков и оплат.
- В «Товарах» название товара остаётся широким, остальные столбцы сделаны компактнее.
- Повторно закреплён утверждённый интерфейс кнопок: светлая левая панель, цветные кнопки-разделы и компактные рабочие кнопки внутри экранов.
- Отправка товарной накладной в WhatsApp жёстко закреплена за JPEG (.jpg). PDF-ветка для кнопки «Отправить в WhatsApp» не используется.
- Добавлены регрессионные тесты, которые не дают вернуть старый крупный интерфейс или PDF-отправку чека.
- База, долги, синхронизация и канонический сервер в этой версии не меняются.

# Учёт дилеров 8.9.67

- «История» перестроена в понятную цепочку: сначала список дилеров, затем накладные выбранного дилера, затем содержимое конкретного чека по двойному нажатию.
- В списке «Товары» убран жирный шрифт у строк товаров.
- Основной список «Долги» и список документов внутри карточки дилера уплотнены по высоте без сжатия по ширине.
- В карточке дилера полностью доработано контекстное меню: оплата — изменить/удалить; накладная — открыть/изменить/удалить; начальный долг — изменить.
- В карточку дилера добавлена кнопка «Внести оплату».
- После сохранения новой продажи автоматически открывается уже сформированная готовая накладная этой продажи, откуда её можно сразу отправить в WhatsApp.
- WhatsApp-чек остаётся JPEG, но строка «Остаток долга» из отправляемого изображения убрана.
- В готовой накладной действие «Скачать накладную» заменено на «Отправить текущий долг».
- Согласованное цветное компактное оформление боковой навигации 8.9.51 сохранено без замены.
- Синхронизация, сервер и каноническая база 8.9.66 в этом пакете не изменяются.

Проверки: полный Windows/macOS prebuild, регрессии предыдущих релизов и отдельные тесты 8.9.67. Публикация допускается только после зелёных CI-проверок.

# Учёт дилеров 8.9.66

- Включены доработки из архива пользователя Uchet-dilerov-macOS-8.9.65-fixed.zip.
- Обновлено оформление кнопок навигации, накладных, JPEG-чеков и отчётов по долгу.
- Устранён конфликт базовых стилей, мешавший ручному изменению ширины столбцов товаров.
- Добавлены сообщения о выборе главного компьютера, передаче роли и ошибках синхронизации.
- Назначение и передача роли главного отменяются, если подтверждение не удалось показать или пользователь нажал «Отмена».
- Сохранены автоматическое резервное копирование перед обновлением и защищённая синхронизация версии 8.9.65.
- При первом подключении рабочего компьютера он получает точную копию базы главного; его прежняя локальная база сохраняется отдельно для сверки и больше не подмешивается автоматически в общий долг.

Проверки включают полный Windows/macOS prebuild, серверные тесты, нативную сборку Apple Silicon и Windows smoke. Финальная публикация выполняется только после зелёных release workflow.

- При отказе ключа (HTTP 401/403) показываются адрес сервера и предупреждение о несинхронизированном долге, без раскрытия ключа.
- Новый Turso-сервер принимает прежний клиентский ключ через SHA-256-проверку: сам секрет не хранится в коде и не публикуется.
