Учёт дилеров 8.9.32

Hotfix механизма обновления.

При обновлении через кнопку «Проверить и установить» обычное окно подтверждения «Остаться / Закрыть программу» больше не вызывается. Нажатие кнопки обновления уже считается явным подтверждением действия.

Новый порядок: резервная копия сохраняется → обновление скачивается и проверяется по SHA-256 → приложению заранее разрешается закрытие → «Учёт дилеров» полностью завершается → отдельный системный помощник ждёт завершения процесса → только после этого запускается установщик.

Обычное подтверждение выхода по крестику сохранено и продолжает работать только при ручном закрытии программы.

Исправления 8.9.30 и 8.9.31 сохранены: удаление дублей дилеров с сохранением истории, синхронизация контактов и удалений между двумя ПК, стандартное меню правой кнопки мыши, удаление товаров с защитой истории, кнопка «Назад», исправления закрытия программы и голосового помощника.

NewMatRos не изменялся.
