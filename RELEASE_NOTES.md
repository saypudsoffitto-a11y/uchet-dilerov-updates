# Учёт дилеров 8.9.55

- Исправлено удаление товаров в общей базе: удалённый товар получает метку удаления, синхронизируется с сервером и больше не возвращается с другого компьютера.
- Пустые карточки товаров без названия, которые отображались строками с прочерками, очищаются и также помечаются удалёнными.
- Исправлен обновлятор для нескольких компьютеров: добавлены запасные адреса GitHub на случай ошибки `fetch failed`.
- Обновление стало платформенным: Windows получает EXE, macOS Apple Silicon — свою сборку.
- Для macOS добавлено автоматическое обновление через ZIP: программа скачивает новую версию, заменяет приложение и запускает его снова; если системная папка недоступна для записи, используется пользовательская папка Applications.
- Экран «Обновление» теперь показывает реальную платформу — Windows или macOS.
- Сохранены все изменения 8.9.54: компактная ширина чека, JPEG по размеру накладной, плотные таблицы, навигация «Назад» и Escape.
