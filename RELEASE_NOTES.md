Учёт дилеров 8.9.42

Стабильная Windows-сборка после трёх подряд полных независимых проверок установленного приложения перед публикацией. Финальный release-workflow повторно выполняет сборку, установку и UI-проверки перед созданием релиза.

Исправлена первопричина, из-за которой часть новых исправлений могла не работать после запуска программы: старый модуль 8.9.30 продолжал через задержанный renderer-патч повторно назначать устаревшие обработчики. Для версий 8.9.41+ этот старый runtime больше не загружается; стандартное меню правой кнопки мыши «копировать/вставить» сохранено.

Исправлен фильтр товаров по группам. Если карточка товара показывает группу, товар теперь отображается при выборе этой группы даже когда в старых данных существовали две визуально одинаковые группы с разными внутренними ID. Одинаковые группы канонизируются, товары перелинковываются на правильную группу, а сравнение дополнительно защищено нормализованным названием группы.

Добавлен реальный Windows UI-тест именно на пользовательский сценарий: создаются одинаково названные группы с разными ID, товар остаётся привязанным к одному из старых ID, затем группа выбирается в интерфейсе — товар обязан оставаться видимым. Этот сценарий прошёл по три раза в каждом из трёх независимых полных Windows-прогонов.

Сохранено и повторно проверено настоящее удаление дилера: правый клик фиксирует точный ID выбранной карточки, удаление создаёт tombstone, карточка исчезает из активного списка и не возвращается после merge/sync. Исторические продажи, чеки, накладные и оплаты сохраняются. Старые патчи 8.9.37/8.9.39 больше не могут перезаписать финальный обработчик, а 8.9.42 повторно закрепляет финальный merge-guard после старых delayed-патчей.

Сохранены восстановление групп из встроенного каталога UTF-8/Windows-1251, горизонтальная прокрутка таблицы товаров, изменение ширины и перестановка столбцов, двусторонняя логика синхронизации, подтверждённый выход из программы, PDF-чек/накладная, PDF-отчёт по долгу и отправка PDF через WhatsApp. Голосовой помощник не возвращён. Интеграция NewMatRos не переделывалась.

Механизм обновления использует GitHub Releases и latest.json с SHA-256. Финальный release-workflow заново собирает Windows Setup/Portable, устанавливает Setup и выполняет реальные UI smoke-прогоны перед публикацией.
