# Учёт дилеров 8.9.16

- Исправлен автоматический расчёт плёнки NewMatRos по ширине рулона.
- Для рулонов до 3,60 м включительно сохраняется отдельная цена узкой плёнки.
- Для MAT-303 шириной 3,80–5,00 м используется цена широкой плёнки.
- Для MAT-303 шириной 5,80 м добавлена отдельная категория и отдельная цена.
- При расчёте NewMatRos программа сначала ищет подходящую цену в карточке товара по материалу, цвету и ширине; ручные цены NewMatRos используются как резерв.
- Для дилерских продаж при найденной карточке товара приоритетно используется оптовая цена, затем розничная.
- Ответ помощника на запрос цены теперь дополнительно показывается отдельным всплывающим окном с названием товара и ценой; окно закрывается вручную.
- В настройках помощника добавлена кнопка «Очистить память помощника». Она очищает только локальные данные и настройки AI-помощника, не затрагивая дилеров, товары, чеки, продажи и долги.
- Голосовой помощник по-прежнему не слушает в фоне, а любые изменяющие действия требуют подтверждения. Голосовое удаление запрещено.
- Сохранены все исправления 8.9.15 и предыдущих версий: синхронизация двух компьютеров, PDF-накладные, WhatsApp Desktop, учёт остатков и исправления интерфейса.

Готово для автоматического обновления с версии 8.9.15.
