Учёт дилеров 8.9.40

Исправлена ошибка нумерации обновления. На компьютере пользователя уже могла быть установлена версия 8.9.39, поэтому повторная публикация исправленной сборки с тем же номером 8.9.39 не могла определяться встроенным обновлятором как новая версия.

8.9.40 содержит актуальный набор сегодняшних исправлений и принудительно имеет новый номер версии, чтобы кнопка «Проверить обновление / Обновить» корректно увидела обновление с 8.9.39 до 8.9.40.

Сохранены и проверяются исправления удаления дилера: правый клик открывает «Изменить карточку дилера» и «Удалить дилера», удаление выполняется по точному ID выбранной карточки, с двойным подтверждением, немедленным сохранением, сохранением старой истории продаж/чеков/оплат и защитой от возврата удалённого дилера после синхронизации.

Также сохранены горизонтальная прокрутка таблицы товаров, компактные таблицы, PDF-накладная для WhatsApp, PDF-отчёт по долгу и исправление очереди синхронизации между компьютерами.

Перед публикацией Windows-сборка должна пройти автоматические тесты, сборку Setup/Portable, установку и три UI smoke-прогона.
