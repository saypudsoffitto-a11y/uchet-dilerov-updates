# Учёт дилеров 8.9.15

- Добавлен голосовой помощник, который запускается только отдельной кнопкой и не слушает в фоне.
- Помощник умеет сообщать цены, остатки товаров и долги дилеров.
- Для продажи помощник может открыть раздел «Новая продажа», выбрать дилера и находить товар по естественно произнесённому названию независимо от порядка слов.
- Добавление товара и другие изменяющие действия выполняются только после явного подтверждения.
- Голосовое удаление товаров, дилеров, чеков и накладных полностью запрещено — удаление только вручную.
- Настройки помощника вынесены в отдельный раздел «Настройки».
- Сохранены исправления 8.9.14 и более ранних версий: начальный/текущий остаток товара, уменьшение остатка после продажи, компактные накладные, PDF для WhatsApp и другие исправления интерфейса.

Готово для автоматического обновления из программы с версии 8.9.14.
