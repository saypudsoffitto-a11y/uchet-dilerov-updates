Учёт дилеров 8.9.30

Исправлено закрытие программы: окно подтверждения «Остаться / Закрыть программу» сохранено, но после подтверждения приложение теперь полностью завершает работу. Добавлен резервный принудительный выход, если Electron или голосовой процесс удерживает приложение после подтверждённого закрытия.

Исправлено удаление дилеров и дублей. По правому клику остаются действия изменения и удаления карточки. При удалении карточка и контакт исчезают из активного списка, но старые продажи, накладные, оплаты и отчёты не удаляются. Перед удалением в операции сохраняется снимок имени и телефона дилера, чтобы старые документы оставались доступными.

Исправлена синхронизация между двумя компьютерами: для изменённых карточек учитывается время последнего изменения, поэтому свежий телефон/контакт больше не перезаписывается старой копией. Для удалённых дилеров и товаров добавлены отметки удаления, чтобы удалённая карточка не появлялась снова после синхронизации. Конфликт «удаление против более позднего редактирования» решается по последнему изменению.

Добавлено стандартное Windows-меню правой кнопки мыши в полях ввода: отменить, повторить, вырезать, копировать, вставить и выделить всё. Ctrl+C / Ctrl+V продолжают работать; номер телефона копируется как введён, включая +, пробелы, скобки и дефисы.

Для товаров добавлено удаление через правую кнопку мыши. Неиспользованный товар удаляется после двух подтверждений. Если товар уже есть в продаже/накладной, он архивируется после двух подтверждений, а история документов сохраняется.

Добавлена кнопка «← Назад» для возврата на предыдущий раздел без очистки введённых в формах данных.

Голосовой помощник сохраняет естественный облачный голос OpenAI (gpt-4o-mini-tts, voice coral) при подключённой облачной речи. В системном режиме 8.9.30 теперь сначала выбирает установленный русский Natural/Neural-голос Windows вместо первого доступного роботизированного голоса. Микрофон по-прежнему включается только по кнопке.

NewMatRos в 8.9.30 не изменялся: рабочая логика 8.9.29 оставлена без доработок.

Перед сборкой выполняются прежние проверки 8.9.29 и дополнительные тесты 8.9.30 для синхронизации, удаления дилера с сохранением истории и разрешения конфликтов между двумя компьютерами.
