Учёт дилеров 8.9.39

Главное исправление — удаление дилера. Найдена причина ложноположительной проверки 8.9.38: Windows smoke-тест успевал проверить обработчик 8.9.37 до того, как поздний патч 8.9.38 подменял его в реальном приложении.

В 8.9.39 после загрузки всех старых и новых патчей принудительно восстанавливается проверенный обработчик удаления 8.9.37 как финальный обработчик интерфейса. Правый клик по дилеру открывает меню с «Изменить карточку дилера» и «Удалить дилера»; удаление выполняется по точному ID выбранной карточки, с двойным подтверждением, немедленным сохранением и сохранением старой истории продаж, чеков и оплат.

Windows smoke-тест изменён: он теперь ждёт появления финального маркера 8.9.39 и только после этого имитирует реальный правый клик, нажимает «Удалить дилера» и проверяет одновременно четыре вещи: запись исчезла из state, исчезла из localStorage, исчезла из видимой таблицы и не возвращается после merge синхронизации. Проверяется также, что соседний дубль остаётся.

Остальные изменения 8.9.38 сохраняются: горизонтальная прокрутка товаров, компактные таблицы, PDF-накладная WhatsApp и PDF-отчёт по долгу.
