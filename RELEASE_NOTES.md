# Учёт дилеров 8.9.88

- Исправлена ситуация, когда после успешного подключения разные компьютеры могли продолжать показывать разные итоговые суммы.
- При получении свежей серверной базы локальные продажи и оплаты теперь проходят строгую трёхстороннюю сверку с предыдущей подтверждённой базой.
- Если локальное финансовое изменение уже конфликтует с серверной операцией, оно больше не блокирует весь обмен и не оставляет компьютер на старой сумме: рабочая база принимает серверную версию, а конфликт сохраняется отдельно для восстановления.
- Независимые новые продажи и оплаты по-прежнему отправляются на сервер и не теряются; подтверждённые операции повторно не создаются.
- После успешной синхронизации клиенты сходятся к одной серверной истории операций и одинаковым итогам.

# Учёт дилеров 8.9.87

- Ошибки данных и конфликты синхронизации больше не маскируются под потерю соединения. Локальные изменения сохраняются до успешного обмена.
