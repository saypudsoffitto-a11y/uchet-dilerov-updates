Учёт дилеров 8.9.41

Стабильная Windows-сборка после трёх полных независимых проверок перед релизом.

Исправлено восстановление отсутствующих групп товаров из встроенного каталога: CSV теперь корректно читается как UTF-8, а для старого каталога с кириллицей автоматически используется Windows-1251. Восстановление групп не угадывает группу по тексту товара, сохраняет связи product/group и устраняет дубли групп.

Сохранено и повторно проверено настоящее удаление дилера: правый клик фиксирует точный ID выбранной карточки, удаление создаёт tombstone, карточка исчезает из активного списка и не возвращается после синхронизации. Исторические продажи, чеки, накладные и оплаты сохраняются.

Сохранена горизонтальная прокрутка таблицы товаров, чтобы на узких экранах и втором компьютере можно было мышкой просматривать все столбцы. Также сохранены изменение ширины и перестановка столбцов.

Проверена двусторонняя логика синхронизации: изменения не теряются во время параллельного pull/push, удалённые дилеры не восстанавливаются из удалённого состояния, данные дилеров и начального долга входят в общий payload.

Голосовой помощник не возвращён. Сохранены стандартные функции правой кнопки мыши и текстовых полей, подтверждённый выход из программы, PDF-чек/накладная и PDF-отчёт по долгу с отправкой через WhatsApp. Интеграция NewMatRos не переделывалась.

Механизм обновления использует GitHub Releases и latest.json с SHA-256. Перед публикацией release-workflow заново собирает Windows Setup/Portable, устанавливает Setup и выполняет три UI smoke-прогона установленного приложения.
