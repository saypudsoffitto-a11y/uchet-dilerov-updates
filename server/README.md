# Общая база «Учёт дилеров»

Сервер хранит одно общее состояние программы и синхронизирует 2–3 компьютера через интернет.

## Переменные окружения

- `PORT` — порт сервера, обычно задаётся хостингом автоматически.
- `SYNC_TOKEN` — секретный ключ. Один и тот же ключ вводится на всех компьютерах в разделе «Общий сервер».
- `DATA_DIR` — папка постоянного хранения базы. На хостинге её нужно привязать к persistent disk/volume.

## Запуск

```bash
npm start
```

Проверка сервера:

```text
GET /health
```

Работа приложения:

```text
GET /api/state
PUT /api/state
Authorization: Bearer <SYNC_TOKEN>
```

На всех компьютерах в приложении откройте «Общий сервер», укажите один и тот же HTTPS-адрес сервера и одинаковый секретный ключ, включите автоматическую синхронизацию и сохраните настройки.

Важно: для реальной эксплуатации каталог `DATA_DIR` должен находиться на постоянном диске, иначе при пересоздании контейнера база может обнулиться.
