## Следующее исправление: удаление из списка товаров в новой продаже

По запросу Ромы добавить пункт «Удалить товар» в меню правой кнопки мыши. Перед разрешённым удалением спрашивать подтверждение дважды; отказ на любом шаге отменяет действие.

Условие пользователя дословно: «При удалении, если на этот товар есть карточка, не удаляй товар. Если она без товара, то разреши удалить товар». Требует уточнения: каждая строка текущего списка уже является карточкой товара. Возможно, имеется в виду наличие остатка или использование товара в накладных, но это не подтверждено. Не включать удаление до уточнения. Существующие правила сохранения истории и защиты использованных товаров сохраняются.

Пункт сохранён для следующего релиза; код удаления пока не изменён. Релиз только по отдельной команде пользователя.
